# Trap Dungeon（トラップダンジョン）

Python と pygame で制作した、トラップを避けてゴールを目指す2Dダンジョン探索ゲームです。
ゴールに着くたびに新しいマップが自動生成され、プレイヤーの被弾の記録をもとに危険を知らせるヒント機能を備えています。

![プレイ画面](screenshot.png)

| 色 | 意味 |
| --- | --- |
| 緑 | プレイヤー |
| 黒 | 通路 |
| 白 | 壁 |
| 赤 | 固定トラップ（踏むとHP-1） |
| オレンジ | 動き回るトラップ（当たるとHP-1） |
| 黄 | ゴール（+100点、次のマップへ） |

## 遊び方

```bash
pip install pygame
python game-meiro.py
```

- `W` `A` `S` `D`：上・左・下・右に移動
- HPは3。0になるとゲームオーバー
- ゲームオーバー画面で `R`：リトライ／`Q`：終了

## 制作の目的

研究で扱っている「プレイヤーの失敗パターンをプレイログから検出する」という考え方を、小さなゲームで試すために制作しました。

## 工夫した点

### 1. 必ずクリアできるマップの自動生成
ランダムウォークで通路を掘ってマップを作るため、トラップの配置によってはゴールにたどり着けないマップができてしまう問題がありました。
そこで、幅優先探索（BFS）でスタートからゴールまで固定トラップを通らずに到達できるかを判定し、到達できない場合はマップを作り直すようにしました（`is_reachable`）。これにより、毎回必ずクリア可能なマップを保証しています。

### 2. 被弾ログにもとづくヒント機能
被弾したときの位置と直前の移動方向をログとして記録し、同じ状況で再び被弾しそうなときに、画面右側に `AI: RISK DETECTED!` という警告を表示します。

### 3. 不具合の修正
動作確認の中で、マップが切り替わっても前のマップの被弾ログが残り、無関係な場所で警告が出る不具合が見つかりました。ゴール到達時にログを初期化するよう修正しています。

## 今後の課題

- 現状の警告は「危険」を伝えるだけで、どう避ければよいかまでは示せていません。失敗の原因に応じた具体的な助言を出せるようにしたいと考えています。
- 固定トラップと動くトラップで記録する位置の意味が異なっており、ヒントの判定条件を整理し直す余地があります。
- 動くトラップは、プレイヤーに当たったあと画面の隅に移動して止まる仕様になっています。今後は再出現させるなど、挙動を見直す予定です。
